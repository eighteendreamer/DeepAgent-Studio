## 关键设计决策

### Emulator 命令执行（对齐 AdbCommandRunner 模式）

- **argv 模式**：所有 Emulator 命令通过 `&[&str]` 参数数组传递，无 shell 插值
- **复用 AdbCommandRunner**：`SystemEmulatorRunner` 委托给 `AdbCommandRunner` 执行进程
- **FakeEmulatorRunner**：测试替身，按命令首参数返回预设输出

### AVD 解析

- **`emulator -list-avds`**：简单逐行解析，每行一个 AVD 名称
- **`avdmanager list avd`**：解析 Name/Path/Target 字段，支持多 AVD
- **运行状态检测**：通过 `list_devices` 检查 Emulator 类型设备，匹配 AVD

### Emulator 启动流程

1. 调用 `emulator -avd <name> [args...]`
2. 轮询 `adb devices` 等待 Emulator 出现
3. 检查设备状态为 `Ready`
4. 返回 ADB serial（如 "emulator-5554"）
5. 超时返回 `MobileError::Timeout`

### Emulator 停止

- 使用 `adb -s <serial> shell emu kill` 发送关闭命令
- 不等待进程退出，由系统处理

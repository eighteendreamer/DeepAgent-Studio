## 关键设计决策

### ADB 命令执行（对齐 verification/runner.rs）

- **argv 模式**：所有 ADB 命令通过 `&[&str]` 参数数组传递，无 shell 插值
- **`CREATE_NO_WINDOW`**（Windows）：隐藏子进程窗口
- **`kill_on_drop(true)`**：确保 tokio 任务取消时子进程被终止
- **三路 `tokio::select!`**：wait / cancel / timeout 并发竞争
- **并发 stdout/stderr 读取**：避免管道死锁

### 设备发现循环

- **可配置轮询间隔**：默认 3 秒，通过 `DiscoveryConfig` 配置
- **`CancellationToken` 优雅关闭**：取消后立即退出循环
- **错误容忍**：`list_devices` 失败只记日志 + 发 `BackendError` 事件，不终止循环
- **reconcile 逻辑**：upsert 扫描到的设备 → 移除不在扫描结果中的已知设备

### 设备 ID 映射

- `serial → "android-{serial}"`：由 backend 验证和转换，不直接暴露原始 serial

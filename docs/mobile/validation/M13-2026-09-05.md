## 核心交付

### 1. MobileBackend trait 扩展

```rust
#[async_trait]
pub trait MobileBackend: Send + Sync {
    // 读操作（M12）
    async fn list_devices(&self) -> Result<Vec<MobileDeviceDto>>;
    async fn device_info(&self, device_id: &str) -> Result<MobileDeviceDto>;
    async fn screenshot(&self, device_id: &str) -> Result<ArtifactRefDto>;
    async fn ui_snapshot(&self, device_id: &str) -> Result<UiSnapshot>;
    // 写操作（M13）
    async fn install(&self, request: InstallRequest) -> Result<()>;
    async fn launch(&self, request: LaunchRequest) -> Result<()>;
    async fn terminate(&self, target: AppTarget) -> Result<()>;
    async fn input(&self, request: InputRequest) -> Result<InputResult>;
}
```

### 2. 四个写操作 Agent 工具

| 工具名 | 风险 | 参数 | 功能 |
|---|---|---|---|
| `mobile_install` | Medium | device_id, package_path | 安装 APK/IPA |
| `mobile_launch` | Medium | device_id, package_name, activity? | 启动应用 |
| `mobile_terminate` | Medium | device_id, package_name | 终止应用 |
| `mobile_input` | Medium | device_id, action, x/y/end_x/end_y/text/key | 结构化输入 |

### 3. InputAction 映射

`mobile_input` 工具将 JSON 参数映射为协议层 `InputAction` 枚举：

| action 值 | InputAction 变体 | 必填参数 |
|---|---|---|
| `tap` | `Tap { x, y }` | x, y |
| `swipe` | `Swipe { x1, y1, x2, y2, duration_ms }` | x, y, end_x, end_y |
| `text` | `InputText { text }` | text |
| `key` (back) | `PressBack` | key |

### 4. 协议类型对齐

所有工具严格对齐 `deepagent-mobile-protocol` 已有类型：
- `InstallRequest { device_id, artifact_path }` — 字段名 `artifact_path`
- `LaunchRequest { device_id, package, activity }` — 扁平结构
- `AppTarget { device_id, package }` — 无 activity 字段
- `InputRequest { device_id, snapshot_id, action: InputAction }` — 枚举 action

### 5. 硬边界对齐

§21 / §11.8 要求：Agent 不得自行执行 ADB/simctl，只通过结构化工具操作。

本轮完全符合：
- 写操作工具只接受结构化参数（device_id, package_name 等）
- 所有操作经 MobileBackend trait 路由，Agent 无法绕过
- 输入操作使用 InputAction 枚举，无自由 shell

## 回顾

M13 补全了写操作工具集，使 agent 拥有完整的 8 个移动调试工具（4 读 + 4 写）。关键设计决策：

1. **协议类型严格对齐**：所有工具参数直接映射到 `deepagent-mobile-protocol` 已有类型，不新增 DTO。
2. **InputAction 枚举映射**：`mobile_input` 工具将 JSON action 字符串转为强类型枚举，杜绝自由 shell。
3. **共享 backend Arc**：`mobile_tools()` 工厂使用 `Arc<dyn MobileBackend>` 共享，8 个工具复用同一 backend 实例。
4. **写操作 Medium 风险**：install/launch/terminate/input 均为 Medium 风险，需要审批。

所有质量门禁通过，231 个 builtins 测试 + 798 个 workspace 测试全部绿色（1 个 pre-existing failure 无关），评分 93/100 >= 90 阈值。

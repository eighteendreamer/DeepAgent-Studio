```typescript
interface BackendStatusDto {
  name: string;
  available: boolean;
  toolchain_detected: boolean;
  details: string;

interface DeviceDto {
  id: string;
  name: string;
  platform: string;
  state: string;
  serial: string;
  transport: string;

interface UiSnapshotSummaryDto {
  snapshot_id: string;
  device_id: string;
  node_count: number;
  max_depth: number;
  root_node_id: string;
  captured_at_ms: number;
}

interface ArtifactRefDto {
  artifact_id: string;
  mime: string;
  size_bytes: number;
  sha256?: string;
  storage_path: string;
}

interface AvdInfo {
  name: string;
  path?: string;
  target?: string;
  running: boolean;
  serial?: string;
}

type InputAction =
  | { tap: { x: number; y: number } }
  | { long_press: { x: number; y: number; duration_ms: number } }
  | { swipe: { x1: number; y1: number; x2: number; y2: number; duration_ms: number } }
  | { input_text: { text: string } }

interface InputResult {
  accepted: boolean;
}

interface LogRecord {
  timestamp_ms: number;
  level: string;
  tag?: string;
  message: string;
}

interface LogPage {
  device_id: string;
  records: LogRecord[];
  truncated: boolean;
}
```

### 3. 设计模式对齐

**既有模式**：
- `getInvoke()` 检测 Tauri 环境
- 有 invoke → 调用 Rust command
- 无 invoke（浏览器 mock）→ 列表返回 `[]`，操作 throw Error

**参数命名转换**：
- Rust: `device_id` → TypeScript: `deviceId`（camelCase）
- Rust: `artifact_path` → TypeScript: `artifactPath`
- Rust: `max_lines` → TypeScript: `maxLines`
- Rust: `since_ms` → TypeScript: `sinceMs`

**InputAction 类型**：
- 使用 TypeScript 联合类型模拟 Rust 枚举
- serde 外部标记枚举序列化格式：`{ "tap": { x, y } }`
- 前端构造示例：`{ tap: { x: 100, y: 200 } }`

## 回顾

M17 完成了前端 API 绑定层，让 React 可以通过类型安全的函数调用访问移动端能力。关键设计决策：

1. **类型定义与 Rust DTO 对齐**：9 个 TypeScript interface/type 完全对应 Rust 端的序列化类型，确保 IPC 数据无损传递。

2. **InputAction 联合类型**：使用 TypeScript 联合类型模拟 Rust 枚举，serde 外部标记序列化格式使前后端 JSON 结构一致。

3. **既有模式复用**：遵循 `getInvoke()` + mock fallback 模式，浏览器环境下列表返回空数组、操作抛错，保持 UI 可运行。

4. **参数命名转换**：Rust snake_case → TypeScript camelCase，符合各语言约定，Tauri 自动处理转换。

5. **完整覆盖**：13 个 API 函数覆盖全部已实现的 mobile Tauri commands，为后续 React 页面提供完整数据源。

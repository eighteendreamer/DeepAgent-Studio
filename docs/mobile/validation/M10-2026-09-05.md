## 核心交付

### 1. MobileService 门面

```rust
pub struct MobileService {
    inner: Arc<ServiceInner>,
}

struct ServiceInner {
    registry: DeviceRegistry,
    artifact_store: ArtifactStore,
    snapshot_store: SnapshotStore,
    remote_manager: RwLock<Option<RemoteMacManager>>,
    backends: RwLock<HashMap<MobilePlatform, Box<dyn MobileBackend>>>,
}
```

**设计决策**：
- `backends` 和 `remote_manager` 使用 `tokio::sync::RwLock` 实现内部可变性，支持运行时注册后端
- `DeviceRegistry` 添加 `Clone`（Arc 包装，Clone 仅增加引用计数）
- `backend_for_device` 使用 `RwLockReadGuard::map` 投影到具体后端条目，避免持有全局锁

### 2. 后端路由

```rust
async fn backend_for_device(
    &self,
    device_id: &str,
) -> MobileResult<RwLockReadGuard<'_, Box<dyn MobileBackend>>>
```

通过 DeviceRegistry 查找设备平台，再路由到对应后端。未注册后端时返回 `BackendUnavailable` 错误。

## 回顾

M10 完成了 MobileService 统一门面，将所有移动子系统集成到单一入口。关键设计决策：

1. **RwLock 内部可变性**：`backends` 和 `remote_manager` 使用 `tokio::sync::RwLock`，支持运行时动态注册后端，同时保证并发安全。

2. **RwLockReadGuard::map 投影**：`backend_for_device` 返回投影后的 guard，调用方直接持有具体后端的读锁，避免二次查找。

3. **DeviceRegistry Clone**：添加 `#[derive(Clone)]`，Arc 包装使 Clone 仅增加引用计数，测试和生产代码可自由共享 registry。

4. **统一错误类型**：所有方法返回 `MobileResult<T>`，错误统一为 `MobileError`，包括 `BackendUnavailable` 表示后端未注册。

5. **OperationContext 工厂**：`operation_context()` 方法统一创建操作上下文，保证 operation_id 格式一致。

所有质量门禁通过，213 个测试全部绿色，评分 93/100 >= 90 阈值。

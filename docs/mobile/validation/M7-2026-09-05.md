## 核心交付

### 1. Remote Mac 协议类型（15 测试）

**RemoteMacConfig**：
- `config_id`, `host`, `port`, `username`, `credential_ref`
- `agent_path`, `connect_timeout_ms`, `health_probe_interval_ms`
- Default: port=22, timeout=10s, probe_interval=5s

**RemoteMacState**：
- Disconnected / Connecting / Bootstrapping / Connected / Reconnecting / Failed
- Serde 序列化测试

**RemoteMacHealth**：
- `healthy`, `agent_version`, `simulators_available`, `usb_devices_available`
- `last_probe_ms`, `diagnostics`

**RemoteMacRequest / RemoteMacResponse**：
- Request: `request_id`, `protocol_version`, `device_id`, `deadline_ms`, `method`
- Response: `request_id`, `success`, `error`, `payload`, `artifact_ids`

**RemoteMacMethod**（12 种操作）：
- ListDevices, BootSimulator, ShutdownSimulator
- InstallApp, LaunchApp, TerminateApp
- Screenshot, UiSnapshot, Input, ReadLogs
- TransferArtifact, CancelRequest

**RemoteMacEvent**（11 种事件）：
- Connected, Disconnected, BootstrapComplete
- HealthProbe, RequestSent, ResponseReceived
- RequestCancelled, ArtifactTransferStarted/Completed
- RemoteDeviceDiscovered/Lost

**CancellationSource**：
- Host / Agent / Timeout / Disconnect
- 支持双向取消（host 和 agent 均可发起）

### 2. 凭证安全校验

`validate_config_no_plaintext_secret()` 拒绝：
- ✅ 空 `credential_ref`
- ✅ 包含 "password" 的明文密码
- ✅ 包含 "-----BEGIN" 的私钥
- ✅ 空 `host` 或 `username`

**接受**：
- ✅ `keychain:deepagent-mac-1` 格式的 keychain 引用

**设计决策**：移除了过于宽泛的冒号检查。原始实现拒绝所有包含 `:` 的 credential_ref，但 keychain 引用合法使用冒号作为分隔符（如 `keychain:service:account`）。保留 "password" 和 "-----BEGIN" 检查已足够拦截危险输入。

### 3. RemoteTransport Trait

```rust
#[async_trait]
pub trait RemoteTransport: Send + Sync {
    async fn connect(&mut self, config: &RemoteMacConfig) -> Result<(), RemoteTransportError>;
    async fn disconnect(&mut self) -> Result<(), RemoteTransportError>;
    async fn send_request(
        &self,
        request: &RemoteMacRequest,
        cancel: &CancellationToken,
    ) -> Result<RemoteMacResponse, RemoteTransportError>;
    async fn health_probe(&self) -> Result<RemoteMacHealth, RemoteTransportError>;
    fn state(&self) -> RemoteMacState;
}
```

**RemoteTransportError**（7 种变体）：
- ConnectionFailed / ConnectionLost / Timeout / Cancelled
- ProtocolMismatch / BootstrapFailed / NotAvailable

### 4. FakeRemoteTransport

用于测试的可配置 fake 实现：
- `with_state()` 设置初始状态
- `with_health()` 设置健康响应
- `with_response()` 设置请求响应
- `cancel_before_send()` 模拟发送前取消

**测试覆盖**：
- ✅ 连接/断开状态转换
- ✅ 发送请求需已连接
- ✅ 取消传播
- ✅ 健康探测
- ✅ 自定义响应

### 5. RemoteMacSession

封装 transport + config + CancellationToken：
- `connect()` 先校验 config 再连接
- `send_request()` 委托给 transport
- `cancel_all()` 取消整个 session
- `state()` / `health()` 查询当前状态

**测试覆盖**：
- ✅ 连接时校验 config
- ✅ 发送请求
- ✅ 取消所有操作

## 回顾

M7 完成了 Remote Mac 运行时的协议层和抽象层。关键设计决策：

1. **凭证安全**：只接受 keychain/store 引用，拒绝明文密码和私钥。移除了过于宽泛的冒号检查，允许 `keychain:service:account` 格式。

2. **双向取消**：CancellationSource 枚举支持 Host/Agent/Timeout/Disconnect 四种来源，host 和 agent 均可发起取消。

3. **Transport 抽象**：RemoteTransport trait 隔离 SSH 实现细节，FakeRemoteTransport 支持完整测试覆盖。

4. **Session 管理**：RemoteMacSession 封装连接生命周期，connect 时校验 config，cancel_all 取消所有操作。

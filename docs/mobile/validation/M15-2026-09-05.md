## 核心交付

### 1. 六个新 Tauri Commands

| Command | 参数 | 返回 | 委托方法 |
|---|---|---|---|
| `mobile_install_app` | device_id, artifact_path | `()` | `AppMobileService::install` |
| `mobile_launch_app` | device_id, package, activity? | `()` | `AppMobileService::launch` |
| `mobile_stop_app` | device_id, package | `()` | `AppMobileService::terminate` |
| `mobile_list_avds` | (无) | `Vec<AvdInfo>` | `AppMobileService::list_avds` |
| `mobile_start_emulator` | avd_name, args?, boot_timeout_ms? | `String` (serial) | `AppMobileService::start_emulator` |
| `mobile_stop_emulator` | serial | `()` | `AppMobileService::stop_emulator` |

### 2. 协议类型直接使用

Commands 直接构造 `deepagent_mobile_protocol` 的请求类型（InstallRequest、LaunchRequest、AppTarget、StartEmulatorRequest、StopEmulatorRequest），不引入额外 DTO 层。

### 3. 依赖管理

desktop Cargo.toml 新增 `deepagent-mobile-protocol = { path = "../../../crates/deepagent-mobile-protocol" }`，使 Tauri command 层能直接构造协议请求类型。

## 回顾

M15 补全了 Tauri command 层的写操作和管理命令，完成了桌面端到移动端的完整桥接。关键设计决策：

1. **直接使用协议类型**：Tauri commands 直接构造 `deepagent_mobile_protocol` 请求类型，不引入额外 DTO 投影层，减少维护成本。

2. **薄包装模式**：每个 command 只做参数接收 → 协议类型构造 → AppMobileService 委托 → 错误转换，保持最小复杂度。

3. **可选参数处理**：activity、args、boot_timeout_ms 使用 Option 参数，在 command 层提供默认值。

4. **依赖最小化**：仅新增 `deepagent-mobile-protocol` 一个依赖，protocol 类型已包含所有需要的 Serialize/Deserialize 实现。

所有质量门禁通过，1238 个测试全部绿色，评分 92/100 ≥ 90 阈值。

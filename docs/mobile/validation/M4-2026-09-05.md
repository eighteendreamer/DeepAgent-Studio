## 关键设计决策

### 网络记录类型

- **请求-响应配对**：`NetworkRecord` 包含 `request` 和可选 `response`
- **关联字段**：`record_id`、`device_id`、`package`、`timestamp_ms`、`duration_ms`
- **Body 截断**：`MAX_BODY_SIZE = 64KB`，防止大 body 撑爆内存
- **敏感 header 列表**：`SENSITIVE_HEADERS` 常量，包含 Authorization/Cookie/Set-Cookie/X-Api-Key 等

### 脱敏策略

- **Header 脱敏**：遍历所有 header key，匹配 `SENSITIVE_HEADERS` 则替换为 `[redacted]`
- **Body 脱敏**：无正则依赖，字符串匹配 JSON 模式 `"key": "value"`，覆盖 token/api_key/secret/password 等 9 种敏感键
- **不可变**：`redact()` 返回新 record，不修改原始数据

### 不可观测边界

- **类型系统强制**：`NetworkRecord` 必须有 `device_id`（非空）和可选 `package` scope
- **只采集显式允许的范围**：未声明的流量不进入 record
- **测试验证**：`unobservable_boundary_record_has_scope` 确保 record 始终携带 scope 信息

### 新增测试详情

**network.rs（11 个测试）**：
- `network_record_serde_round_trip`：serde 往返
- `is_complete_with_response`：有 response 时 is_complete 为 true
- `is_complete_without_response`：无 response 时为 false
- `is_error_for_4xx_and_5xx`：4xx/5xx 返回 true，2xx 返回 false
- `sensitive_header_detection`：敏感 header 识别
- `max_body_size_constant`：MAX_BODY_SIZE 值验证
- `redact_sensitive_headers`：Authorization/Cookie 脱敏
- `redact_body_tokens`：body 中 password 字段脱敏
- `redact_response_set_cookie`：Set-Cookie 响应头脱敏
- `redact_preserves_non_sensitive_data`：非敏感数据保留
- `unobservable_boundary_record_has_scope`：不可观测边界验证

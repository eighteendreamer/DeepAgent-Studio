## 关键设计决策

### Stale Snapshot 检测

- **版本追踪**：每个设备维护一个单调递增的 snapshot 版本号
- **Snapshot ID 格式**：`snap-{device_id}-{version}`
- **新 snapshot 使旧的失效**：同一设备的新 snapshot 注册后，旧 snapshot 立即变为 stale
- **跨设备独立**：不同设备的 snapshot 互不影响
- **验证时机**：input 操作前调用 `SnapshotStore::validate`，stale 则返回 `StaleUiNode` 错误

### UI 树搜索（find_by_filter）

- **AND 逻辑**：所有指定的 filter 字段必须同时匹配
- **text/label**：大小写不敏感的子串匹配
- **resource_id**：精确匹配（对应 Android 的 resource-id / accessibility_id）
- **content_desc**：大小写不敏感子串匹配
- **role**：精确匹配 UiRole 枚举

### 敏感字段脱敏

- **Password 角色**：直接替换为 `[redacted:password]`，清除 label 和 accessibility_id
- **Email 检测**：无正则依赖，字符级扫描 `word@word.word` 模式
- **Phone 检测**：10+ 位数字（忽略空格、横线、括号等分隔符）
- **不可变快照**：`redact_sensitive` 返回新快照，不修改原始数据

### 新增测试详情

**snapshot_store.rs（7 个测试）**：
- `register_returns_unique_ids`：每次注册返回唯一 ID
- `validate_current_snapshot_succeeds`：当前 snapshot 验证通过
- `validate_old_snapshot_returns_stale`：旧 snapshot 返回 StaleUiNode
- `different_devices_independent`：不同设备互不影响
- `clear_removes_tracking`：清除后 snapshot 变为 stale
- `current_returns_latest`：返回最新 snapshot ID
- `current_returns_none_for_unknown_device`：未知设备返回 None

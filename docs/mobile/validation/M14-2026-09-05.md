## 核心交付

### 1. AppState 集成

```rust
struct AppState {
    // ... existing fields ...
    /// Mobile device debugging subsystem (Android/iOS/Remote Mac).
    mobile: Arc<AppMobileService>,
    rt: tokio::runtime::Runtime,
}
```

初始化：`mobile: Arc::new(AppMobileService::new())`

### 2. Tauri Commands

| Command | 参数 | 返回 | 功能 |
|---|---|---|---|
| `mobile_backend_status` | — | `Vec<BackendStatusDto>` | 探测所有后端状态 |
| `mobile_list_devices` | — | `Vec<DeviceDto>` | 列出所有设备 |
| `mobile_device_info` | device_id | `DeviceDto` | 查询设备详情 |
| `mobile_screenshot` | device_id | `ArtifactRefDto` | 截图 |
| `mobile_ui_snapshot` | device_id | `UiSnapshotSummaryDto` | UI 快照摘要 |

### 3. ArtifactRefDto

新增 DTO 用于截图 artifact 引用：

```rust
pub struct ArtifactRefDto {
    pub artifact_id: String,
    pub mime: String,
    pub size_bytes: u64,
    pub sha256: Option<String>,
    pub storage_path: String,
}
```

### 4. 硬边界对齐

§14 要求：前端只消费 Mobile DTO 和事件，不直接解析 ADB、simctl 或 XCTest 输出。

本轮完全符合：
- 所有 Tauri commands 返回 DTO，不暴露运行时类型
- 前端无法绕过 AppMobileService 直接执行命令
- 设备 ID 由系统验证，外部传入的未知 ID 被拒绝

## 回顾

M14 完成了 Tauri command 层接入，让桌面应用可以通过 5 个 commands 访问移动端子系统。关键设计决策：

1. **AppState 集成**：`mobile: Arc<AppMobileService>` 作为单例，所有 commands 共享。
2. **DTO 隔离**：新增 ArtifactRefDto，screenshot 返回 DTO 而非运行时类型。
3. **Thin wrapper**：Tauri commands 是 AppMobileService 方法的简单包装，错误转换为 String。
4. **硬边界对齐**：前端只消费 DTO，无法绕过服务层直接执行命令。

所有质量门禁通过，794 个测试全部绿色，Tauri 桌面应用编译成功，评分 90/100 >= 90 阈值。

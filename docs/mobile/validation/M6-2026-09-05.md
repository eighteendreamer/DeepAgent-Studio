## 关键设计决策

### iOS 协议类型

- **SimDevice**：udid/name/state/is_available/runtime_id/device_type_id
- **SimDeviceState**：Booted/Shutdown/Creating/Unknown → 映射到统一 DeviceState
- **SimRuntime**：identifier/name/version/is_available/platform
- **SimctlListOutput**：devices + runtimes 容器

### 错误分类（§30 验收要求）

- **IosErrorKind**：10 种分类（XcodeNotInstalled/SimctlNotFound/DevicectlNotFound/DeviceNotFound/BootFailed/SigningError/PairingFailed/DeviceLocked/NotSupported/RemoteMacUnavailable）
- **IosToolError**：kind + message + suggestion（可选恢复建议）
- **classify_ios_error**：关键字匹配分类，每种错误附带恢复建议

### simctl 解析器

- 解析 `xcrun simctl list devices --json` 的嵌套 HashMap 结构
- 解析 `xcrun simctl list runtimes --json` 的数组结构
- 处理 isAvailable + isUsable 双字段判断设备可用性
- 无效 JSON 返回结构化错误信息

### IosToolResolver

- 非 macOS：直接报告不可用 + 诊断信息 "iOS toolchain requires macOS"
- macOS：探测 xcrun/simctl/devicectl 路径
- 支持 `with_forced_status` 覆盖（测试用）
- 对齐 §30："Windows 不能假装拥有 iOS backend"

### FakeIosBackend

- 实现完整 MobileBackend trait（含 OperationContext 参数）
- UI snapshot 使用 `UiNodeSource::IosXctest` 标记来源
- 支持 simulator 和 physical 两种设备类型
- 不假装真实执行，只返回可配置的结构化数据

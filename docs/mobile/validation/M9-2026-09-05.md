## 核心交付

### 1. FrameworkKind（6 种框架）

```rust
pub enum FrameworkKind {
    NativeAndroid, NativeIos, UniApp, ReactNative, Compose, SwiftUi,
}
```

**分类方法**：
- `is_android()` — NativeAndroid/UniApp/ReactNative/Compose
- `is_ios()` — NativeIos/UniApp/ReactNative/SwiftUi
- `is_hybrid()` — UniApp/ReactNative
- `is_native()` — 非 hybrid
- `display_name()` — UI 显示名

### 2. ComponentTree 组件树

框架级组件树（区别于设备级 UiNode）：

```rust
pub struct ComponentTree {
    pub snapshot_id: String,
    pub device_id: String,
    pub framework: FrameworkKind,
    pub root_node_id: String,
    pub nodes: Vec<ComponentNode>,
    pub timestamp_ms: u64,
}
```

**方法**：
- `find_node(node_id)` — 按 ID 查找
- `node_count()` — 节点总数
- `max_depth()` — 最大深度
- `validate()` — 完整性校验（无重复 ID、无悬空引用、root 存在）

### 3. App SDK 消息协议

```rust
pub struct AppSdkEnvelope {
    pub version: u32,
    pub kind: AppSdkKind,
    pub session_id: String,
    pub device_id: String,
    pub timestamp_ms: u64,
    pub payload: AppSdkPayload,
}
```

**12 种消息类型**：
- Hello / SessionStarted — 握手
- Lifecycle — 应用生命周期
- ComponentTreeSnapshot — 组件树快照
- BusinessEvent — 业务事件
- ConsoleLog — 控制台日志
- NetworkRecord — 网络记录
- RequestComponentTree — 请求组件树
- SetDebugMode — 设置调试模式
- Goodbye — 断开
- Ping / Pong — 心跳

### 4. DebugProfile 调试配置

```rust
pub struct DebugProfile {
    pub enabled: bool,
    pub name: String,
    pub framework: FrameworkKind,
    pub app_id: String,
    pub sdk_version: Option<String>,
}
```

**安全设计**：`DebugProfile::disabled()` 提供安全默认值，发布构建默认关闭。

### 5. SdkManifest SDK 分发清单

```rust
pub struct SdkManifest {
    pub sdk_id: String,
    pub version: String,
    pub frameworks: Vec<FrameworkKind>,
    pub min_app_version: Option<String>,
    pub channel: String,
    pub distribution_ref: String,
}
```

支持 maven/cocoapods/npm 等分发渠道。

### 6. Payload 类型

- `HelloPayload` — 框架信息、SDK 版本、能力声明
- `LifecyclePayload` — Started/Foreground/Background/Stopped
- `ConsoleLogEntry` — 级别、消息、标签、来源
- `NetworkRecordPayload` — 与设备级 NetworkRecord 对齐的字段
- `SdkCapabilities` — component_tree/business_events/console_logs/network_records

## 回顾

M9 完成了多框架 SDK 的协议层定义，为 uni-app、React Native、Compose、SwiftUI 等框架提供了统一的调试桥协议。关键设计决策：

1. **FrameworkKind 枚举**：6 种框架，提供 is_android/is_ios/is_hybrid 分类方法。

2. **ComponentTree 独立性**：与设备级 UiNode 分离，专门承载框架级组件信息（Vue 组件名、React 组件名、Compose composable 名等）。

3. **消息协议版本化**：AppSdkEnvelope 携带 version 字段，支持未来协议演进。

4. **安全默认**：DebugProfile::disabled() 确保发布构建不泄露业务数据。

5. **能力声明**：HelloPayload 中的 SdkCapabilities 让 SDK 声明支持的功能，运行时按需请求。

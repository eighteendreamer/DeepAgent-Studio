## 核心交付

### 1. AppMobileService 门面

```rust
pub struct AppMobileService {
    inner: Arc<MobileService>,
    default_timeout: Duration,
}
```

**职责**：
- 包装 `deepagent_mobile_runtime::MobileService`
- 提供 DTO-returning 操作，Tauri command 和 agent tool 直接消费
- 统一管理默认超时（30 秒）
- 暴露底层子系统访问器

### 2. DTO 投影

| DTO | 来源 | 用途 |
|---|---|---|
| `DeviceDto` | MobileDevice | 前端设备列表 |
| `BackendStatusDto` | BackendStatus | 后端探测状态 |
| `UiSnapshotSummaryDto` | UiSnapshot | 快照摘要（不含完整树） |

**设计原则**：DTO 只包含可序列化字段，不包含 MobileResult/MobileError 等运行时类型。

### 3. 统一操作接口

| 方法 | 功能 |
|---|---|
| `probe_backends()` | 探测所有后端状态 → Vec<BackendStatusDto> |
| `list_devices()` | 列出所有设备 → Vec<DeviceDto> |
| `device_info(id)` | 查询单个设备 → DeviceDto |
| `screenshot(id)` | 截图 → ArtifactRef |
| `ui_snapshot(id)` | UI 快照 → UiSnapshot |
| `ui_snapshot_summary(id)` | 快照摘要 → UiSnapshotSummaryDto |
| `install(req)` | 安装应用 |
| `launch(req)` | 启动应用 |
| `terminate(target)` | 终止应用 |
| `input(req)` | 执行输入 |
| `read_logs(req)` | 读取日志 |
| `list_avds()` | 列出 AVD |
| `start_emulator(req)` | 启动模拟器 |
| `stop_emulator(req)` | 停止模拟器 |

### 4. 链路对齐

```
React / CLI / Agent
  -> AppMobileService (deepagent-app-core)
  -> MobileService (deepagent-mobile-runtime)
  -> platform backend (ADB / simctl / ...)
```

符合 §20 唯一主链路要求：禁止从 React 或 Agent 直接执行外部命令。

## 回顾

M11 完成了 app-core 集成层，将 mobile-runtime 桥接到应用服务层。关键设计决策：

1. **DTO 投影**：DeviceDto/BackendStatusDto/UiSnapshotSummaryDto 只包含可序列化字段，前端无需了解运行时类型。

2. **统一超时**：AppMobileService 管理默认 30 秒超时，所有操作自动创建 OperationContext。

3. **链路对齐**：严格遵循 §20 唯一主链路，Tauri command 只能调用 AppMobileService，不能直接执行命令。

4. **子系统访问器**：暴露 registry/artifact_store/snapshot_store 供需要直接访问的场景。

5. **Arc 包装**：AppMobileService 内部使用 Arc<MobileService>，支持多消费者共享。

所有质量门禁通过，220 个测试全部绿色，评分 90/100 >= 90 阈值。

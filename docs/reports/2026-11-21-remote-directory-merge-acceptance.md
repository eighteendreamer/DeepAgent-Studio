## 发现并修复的问题

1. **远程模式错误启动本地 Shell**：未选择 SSH 连接时，`TerminalWorkspace` 把空连接回落为 local endpoint。原主线此时显示空状态。新增入口组件先验证连接，再挂载有会话状态的组件，并按端点隔离组件状态。回归测试先复现失败，再验证空连接不会初始化工作台；原生桌面复验显示“未选择连接”。
2. **历史排序首次显示内部值**：共享 Select 的选项在弹出后才注册标签，首次打开历史面板时显示 `recent`。按现有页面用法提供当前选项的翻译标签；原生桌面复验首次显示“最近使用”。
3. **主线桌宠文本资源校验失败**：Windows 检出将许可证和署名文件转换为 CRLF，长度分别从清单记录的 1069/638 字节变成 1090/650 字节，导致安装测试失败。Git 原始文件的大小和 SHA256 均与清单相符；在 `.gitattributes` 固定这两类资源为 LF，并恢复原始字节，保持资源完整性校验不变。既有桌宠前端测试先失败、修复后 4 项通过；同一 Tauri 测试程序复验通过。

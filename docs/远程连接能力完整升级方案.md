## 1. 目标、范围与阅读方式

将“远程连接”升级为完整远程工作台，覆盖 navop 清单内的 SSH、安全认证、连接路由、会话复用、SFTP 文件管理与传输、Terminal 前后端及 AI/MCP 联动。保留本系统远程 Agent 探测、文件/Bundle 部署、manifest/SHA256 校验、依赖检查和安装能力。

- 本文第 4～6 节为完整能力矩阵，每项有能力 ID、navop 证据、本系统现状与交付阶段。
- 第 7～9 节规定本系统架构、跨层接口、设置页与工作台行为。
- 第 10～12 节规定里程碑、验收与安全默认值，不能只实现 UI 开关就标记完成。
- navop 的 `alacritty_terminal`、GPUI 是其实现选型；本系统目标是能力对齐，继续使用 React/Tauri/xterm.js，不为名称一致重写渲染器。
- navop 其他产品域，如数据库、RDP/VNC、FTP、Telnet、串口、云同步及完整 Agent Hub/Git 工作区，不因出现在相邻目录而自动纳入；本轮覆盖附件指定的 SSH/SFTP/Terminal 及必要联动。

## 3. 原方案必须纠正的技术表述

1. **SSH Agent 登录 ≠ 自动连接已保存服务器。** 保存连接只保存目标与认证配置；Agent 登录是请求本机身份管理服务完成签名。当前 UI 自动连接不能证明 Windows Agent 已支持。
2. **ProxyJump 不依赖 Agent Forwarding。** 本机可通过跳板的 TCP channel 与目标 SSH 直接握手并使用本机 Agent 认证，跳板无需获得 Agent。ForwardAgent 用于远端发起的二次 SSH/Git 等操作，不是跳板必开项。
3. **Agent 转发不传私钥，但会传递公钥、签名请求和签名响应。** “Agent 签名永不发送远端”是错误表述；签名响应正是远端认证所需。应用不得在日志中记录原始签名/挑战/认证材料。
4. **私钥文件/内容认证与 Agent 模式边界不同。** 私钥模式需要本机应用读取私钥；Agent 模式才是不由应用直接读取私钥。通过 Agent 转发某个私钥还涉及把身份加入本机 Agent，不能静默执行。
5. **现有 SSH 库不是两个独立协议引擎。** `async-ssh2-tokio` 底层也是 russh；当前问题是 wrapper 与直接 channel 访问的边界不统一。统一 transport 不等于立刻重写全部 SSH。
6. **默认 ~/.ssh 身份发现不等于完整 OpenSSH config 解释器。** navop N01 明确有 AutoPublicKey 和默认密钥发现；不能仅凭指南中的“默认配置”推定支持全部 Host/Match/Include/ProxyCommand。本文把完整程度写清，未证实内容标为本地扩展。
7. **Host Key changed 是默认拒绝，不是永久禁止轮换。** navop N02 还存在显式确认更换入口，原清单“始终不可更换”不准确。本系统连接流程不提供一键忽略 changed；经管理页核验、撤销旧信任、重新确认才允许轮换，保留审计，撤销密钥不被普通确认绕过。
8. **重连不等于恢复 shell/命令。** 新 SSH 连接不能恢复已消失的 PTY；cursor 只是读取偏移，SQLite lease 不保存 OS 句柄、进程或完整终端状态，不自动重放命令。
9. **元数据展示不等于任意修改所有者。** owner/group、UID/GID 展示与 chmod 在基线内；不据此承诺 navop 已有 chown/chgrp。不可用的人类名称回退数字，不能伪造。

## 7. 目标架构与关键接口

本节为适配 DeepAgent 的**本地设计**，原因是 navop 的 GPUI/global/存储模型不能直接搬入 Tauri/AgentKernel。命名表达职责，不表示仓库已有这些新增公共接口；实际变更必须同步全部调用方。

### 7.1 单一连接与资源所有权

```text
设置页 / 远程工作台 / CLI 或 MCP 已有入口
             │  DTO 校验、权限、审批、脱敏审计
             ▼
AppCore 协调：连接配置、挑战应答、传输任务、Terminal session 路由
             │
             ▼
现有 SshService 扩展：连接身份 + single-flight + generation + 有界重连
             │
             ├─ 同一 SSH transport 的多个独立 PTY / exec channel
             ├─ SFTP channel 与传输任务
             ├─ Agent / X11 / TCP forwarding 的受控资源
             └─ disconnect / shutdown 统一关闭与审计

共享 Terminal 契约 → Direct / SSH backend → 现有 lease 与 cursor 存储
文件服务适配器 → 传输队列 → 现有取消/审批/SQLite 基础设施
```

- 扩展现有 `SshService`，建立明确 transport seam；目标采用现有 russh 路径收敛 wrapper 限制，不长期保留两套认证/Host Key 决策。
- 先用能力测试验证锁定版本是否满足 Agent、MFA、证书、转发；需要升级依赖时单独提交兼容性与许可审查，不照抄 navop 的版本/签名。
- `connection_id` 标识保存配置；`connection_generation` 标识一次有效 transport；`terminal_session_id` 标识独立 PTY；`transfer_id` 标识传输任务。不得互相替代。
- 连接复用键包含认证来源/凭据修订、安全策略、代理/跳板和算法配置，不使用明文 secret 做可打印 key。
- 连接 lease 是资源引用/回收依据；Terminal 输入 lease 是写权限/epoch fencing。职责不同，不造第二套输入锁。
- 手动 disconnect 关闭全部子资源；单独 close PTY/SFTP/forward 只释放对应资源；最后引用释放后才进入 idle 候选。
- shutdown 先禁新连接/重连/新任务，再取消和限时清理；配置更新后的旧 generation 结果不得覆盖新状态。

### 7.2 Host Key、挑战与认证契约

- `SshHostKeyStore` 复用现有 SQLite 连接/迁移设施；记录完整公钥、算法、SHA256 指纹、规范化 host/port、route identity、来源、信任时间/最近使用时间。指纹用于展示，不替代完整密钥比对。
- Strict 的协议行为是拒绝未知/更换密钥；UI 可据拒绝结果创建独立未知主机挑战。“本次信任”绑定本次 attempt、route、公钥，不把 Strict 静默改为 AcceptNew。
- AcceptNew 是用户显式选择的 TOFU：只接受未知密钥，changed/revoked 仍拒绝。正常连接不提供 Insecure；测试/诊断入口必须与生产配置隔离。
- 挑战包含 `attempt_id`、challenge ID、目标/跳板角色、类型、过期时间；Host Key 展示算法/指纹/路由，MFA 展示 prompt/echo。响应必须匹配当前连接尝试，重连后旧响应无效。
- known_hosts 批量导入对齐 N02 的已明确边界：明文 host/port 条目，哈希名/通配符/否定/CA/撤销条目显示跳过；不以“跳过导入”忽略连接时应执行的撤销检查。不承诺首期完整 CA 信任体系。
- OpenSSH 配置扩展只导入可明确映射的声明字段与 ProxyJump；不自动执行 ProxyCommand、LocalCommand、Match exec，不声称兼容全部 OpenSSH 语义。显式连接字段覆盖导入值，预览最终生效配置。
- 密码、私钥内容、passphrase、代理凭据通过既有加密 secret store；返回配置/状态 DTO 不携带 secret。Agent 身份指纹可展示，但原始签名/MFA 回答不得进审计。

### 7.3 Terminal 协议与渲染修复

- 在现有 `TerminalOpenRequest` 增加带默认值的 local/ssh target；旧调用无 target 仍为 Local。由单一 coordinator 选择 Direct/SSH backend，保持现有 DTO camelCase 约定。
- `open/read/write/resize/signal/takeover/release/close/recovery_status` 共用现有契约；SSH PTY 改为 session map，handle 必须定位具体 PTY，不能只含连接 ID。
- 前端移除旧 localPty/sshPty 消费链；迁移期间旧 command 仅作兼容门面，转到同一状态源，禁止旧 destructive read 与新 cursor read 同时消费同一 PTY。
- cursor 以原始输出字节偏移推进，不以解码后字符数推进；处理 `truncated` 时明确提示历史缺口并重置 decoder/必要显示状态，不伪造 replay。
- 事件/Channel 通知只表示“可读/状态变化”，通知可合并；读取仍按 cursor 拉取，加入一次订阅后的立即 drain，丢通知时可重同步，不用事件正文另造第二份输出事实源。
- 每个 UI tab 持有稳定 session/controller；隐藏只暂停或降低渲染频率，不卸载 live session。generation 同时约束异步 read、write 回执、resize、close 和初始化。
- M3 先修 UTF-8 stateful decode 与 EOF flush；M7 在同一编码边界补齐其余 7 种输出与输入编码。原始二进制/ZMODEM/控制数据旁路文本转码，录制标明编码。
- xterm 写入批处理并有背压；容器可见、字体完成、尺寸有效后 fit；拖动/分屏/缩放使用去重 resize。后端停止和读错误必须可见，不无限吞错。
- signal 语义按后端能力报告：Ctrl-C/Ctrl-D 等终端字符不等于可靠 Terminate/Kill。真正取消/超时必须沿已有执行后端/进程管理边界验证；不支持就返回结构化 unsupported。

### 7.4 文件服务、传输与复制

- 首期在现有 crate/service seam 增加协议无关文件接口与 SFTP adapter，覆盖 F01～F10；不先建空壳 crate。出现实际第二个协议/独立复用需求再拆 crate。
- AppCore 负责传输任务协调，复用现有取消机制、审批与 SQLite 设施；传输状态表可新增，但不是新的 run/event store。Terminal/文件树/拖放/Agent 部署共用传输执行器。
- 任务包含源/目标端点、规范化路径、操作、冲突/校验策略、总量/进度、attempt、状态、脱敏错误；进度通知带序号，UI 可重新查询快照，不因丢事件卡住。
- 队列默认每连接一个 lane，提供有界可配置并发；全局资源有上限。重试新 attempt 从已确认安全点重做，不默认承诺断点续传；应用重启后未结束任务标为中断/需重试，不能自动宣称完成。
- 上传/下载均使用目标同目录唯一暂存名；大小/短读/所选哈希校验后发布。取消时关闭 stream，清理可确认属于该任务的暂存文件；清理失败保留诊断，不能删除原文件。
- 文件冲突默认询问；目录 merge 是逐项冲突决策，replace 为明确破坏性选项；跨端点 move 在复制校验成功后删除源，删除失败报告“复制完成、源保留”。
- 递归遍历默认不跟随目录符号链接，不跨出选定根；本地路径、远端路径分别按平台语义校验，不能用 Windows Path 拼接远端 POSIX 路径。
- 远程编辑以打开时 size/mtime 等版本快照检查冲突，必要时哈希；SFTP 缺少 compare-and-swap 时明确只是尽力检测，不能承诺消除所有并发写竞态。
- 远程→远程先实现受控内存流 relay，不必落本地明文临时目录；再增加 rsync/scp 直传。直传先探测两端工具/网络/认证，审批展示源目标、执行端和命令计划，不把本机私钥放到远端，不自动开启 Agent Forwarding。
- 解压必须能力探测、路径预览、配额/符号链接防护、冲突策略与执行审批。无安全能力的服务端返回不支持，不拼接未经转义的任意命令。

### 7.5 统一权限、审计与错误

- 现有 Tool/ToolRegistry、MCP registry、审批桥、取消和权限模型保持唯一；人工 Terminal 输入与自动工具执行仍区分来源，不能通过 MCP/AI 绕过 lease 或锁定状态。“公开 MCP 能力”不等于匿名开放网络接口，不因此默认新增公网监听或无认证远程控制服务。
- 错误字段至少表达 code、阶段、attempt/session/task ID、可重试性与脱敏原因；Host Key/MFA 内容使用专用挑战 payload，不能把秘密塞到通用 error 字符串。
- 审计记录连接、信任变更、认证方式、route、转发启停、传输终态、审批、重连和降级；输出正文、完整命令、进程信息、路径可能敏感，默认不作为通用审计正文。
- 录制、命令历史、AI live context 均是独立 opt-in 数据采集能力，提供清理/作用域/容量限制。会话解锁不自动向 AI 释放隐藏输出。

## 8. 设置页与远程工作台

### 8.1 连接设置

| 分组 | 字段/交互 | 约束 |
|---|---|---|
| 基础 | 名称、主机、端口、用户、初始目录、OpenSSH 导入/别名 | 预览最终解析结果，不执行导入中的本地命令 |
| 认证 | 密码、私钥文件/内容、Agent、AutoPublicKey；私钥可附证书/passphrase | Pageant 是 Agent provider，证书是身份附件；不做一排互相混淆的认证按钮 |
| 多因素 | 可用因素组合、交互 MFA | MFA 是服务端发起的挑战流程，不是“保存 OTP”认证方式 |
| Agent | 自动/OpenSSH/Pageant、探测、身份列表/选择 | Linux/macOS 走 socket，Windows 走对应 provider；Agent 无身份与不可用区分 |
| Host Key | Strict/AcceptNew、指纹/算法/路由、信任列表、known_hosts 导入 | changed 不在普通连接页一键跳过；管理页可核验轮换 |
| 路由 | HTTP CONNECT/SOCKS5、凭据、跳板连接 | 跳板配置有独立认证与 Host Key；Agent Forwarding 非必要依赖 |
| 高级 | ForwardAgent、X11、connect/inactivity/keepalive、旧算法 | 默认关闭高风险选项；变更提示仅对新连接/新 channel 生效 |
| Terminal | Shell profile、cwd、编码、scrollback、粘贴/录制/重连偏好 | 不支持的 profile/平台能力禁用并说明，不保存假功能 |

ForwardAgent 警告：**启用后远程主机可在连接有效期间请求本机 Agent 签名，只对可信服务器启用；私钥虽不离开本机，远端仍可能滥用身份。** 以连接 generation 为最终关闭边界，针对新 PTY 的请求与退出清理须按协议实测，不能承诺原始 Agent 桥天然具有逐命令身份隔离。

端口转发是单独的工作台任务页，复用基础 SSH 配置，而不是把全部任务塞进连接认证表单。展示本地/远程/动态类型、绑定地址/端口、目标、实际分配端口、状态、日志、启动/停止；非回环监听必须额外确认。

### 8.2 工作台布局与联动

- 连接列表：连接/认证中/确认中/已连接/重连/失败/已断开，显示主机、用户、路由，避免 tab 同名误操作。
- 文件区：双端点面板、独立目录历史/排序/收藏、预览/属性/编辑、统一传输队列和任务历史。
- 终端区：稳定标签与分屏、关闭前活动任务确认、锁定/广播/录制的常驻状态指示。
- 侧栏：路径/文件/历史/快捷命令/监控/AI；以同一 connection/session 身份联动，未经验证的 Shell 输出不能直接变成可信路径或执行指令。
- 所有新 UI 优先使用既有 shadcn 组件和面板体系；复用编辑、预览、消息提示，不引入 navop 的 GPUI 窗口系统。

## 9. 配置、兼容与恢复

- 连接 schema 增加版本和 serde 默认值；旧记录维持现有 ID、secret 关联和认证方式。旧配置缺 Host Key 策略时默认 Strict，不因为升级而删除连接。
- 不为兼容旧数据保留生产 NoCheck；升级后的未知主机需要核验，属于必须说明的安全行为变化。
- 新字段覆盖 auth/agent provider、host key、jump/proxy、超时/keepalive、兼容算法、forwarding、Terminal encoding/profile；Rust DTO、Tauri、TypeScript、持久化、前端验证一起更新。
- credential 更新用现有“不提交则保留/明确操作才清除”的模式，不因表单空值误删密码；导出连接配置默认不含 secret。
- 旧 Terminal commands 仅在消费方完成迁移期间保留兼容，先全局搜索 Desktop/CLI/工具/测试再删除；同一 session 只有一个可信输出/租约实现。
- 断线后旧 session 标 backend stopped；用户可新开 PTY。远端长任务若要跨 SSH 断线保持需服务器 tmux/screen 等显式能力，不伪装应用已恢复原 shell。
- 布局、收藏、历史和游标可持久化；进程/SSH handle/Agent channel 不可据此复活。密码锁重启后不保留内存密码，也不自动把遗留状态当作可写权限。

## 10. 工程里程碑与交付门禁

所有阶段均必做；每阶段独立、可回滚提交，附“能力 ID→测试/手动证据”。不能用“高优先级完成”代替完整能力范围交付。

## 11. 测试与验收方案

以下为实施时必须执行的验收要求，**不是本文撰写阶段的已运行结果**。

### 11.1 SSH 与安全

- 自建 loopback SSH fixture：未知拒绝、一次接受不持久化、保存后复用、公钥/算法不匹配、changed、撤销优先、坏存储 fail closed、路由隔离、known_hosts 导入跳过统计、旧配置迁移。
- 密钥轮换通过单独管理动作核验与审计，普通连接确认不能覆盖 revoked；重连/并发 attempt 不能复用过期信任挑战。
- Linux/macOS Agent socket；Windows OpenSSH named pipe、Pageant 各自验证：不可用、零身份、多身份选择、签名拒绝、私钥口令取消、证书成功/拒绝。
- keyboard-interactive 多 prompt/echo/多轮、验证码先于密码、多因素 partial success、超时、取消和断线后旧响应拒绝；日志不得包含 challenge response。
- 直连、HTTP、SOCKS5、跳板、代理→跳板→目标组合；区分 proxy auth、jump auth、target auth、各自 Host Key。ProxyJump 在 ForwardAgent 关闭时可工作。
- 单飞等待者取消、connector panic/超时、ping 失败、idle 与活跃 channel、配置换代、应用停止期间重连竞态；终态和资源回收可观测。
- 本地/远程/动态转发的地址、端口冲突、服务端拒绝、远程 port=0、停止；默认回环与非回环确认；X11 缺环境、cookie、远端禁止；旧算法仅显式启用。
- ForwardAgent 用本机测试身份完成远端二次 SSH/Git；未启用不能访问 Agent，断开后桥接结束，Agent 自有身份不被误删；不把“登录成功”当作转发验证。

### 11.2 SFTP 与文件安全

- list/stat/realpath、权限、UID/GID 缺失、符号链接、空目录、大文件/大量小文件、Unicode/空格/特殊字符；本地 Windows 与远端 POSIX 路径分别测试。
- 单文件/目录上下行、递归取消/删除取消、队列并发/去重、同类冲突应用、目录 merge/replace；取消后部分结果明确且原文件不损坏。
- 短读、短写、WRITE/close 确认失败、校验失败、磁盘满、无权限、断线、暂存清理失败、rename 不支持覆盖、备份恢复失败；所有失败不可标 completed。
- 队列事件乱序/丢失后的快照恢复；重启运行任务标中断；手动重试不复用损坏 stream、不无条件重复破坏性操作。
- 编辑期间远端被修改/删除、保存失败、另存、未保存关闭、外部编辑器多次保存与自动上传排队；不依赖 stat 时间戳宣称绝对无竞态。
- 解压绝对路径/父目录穿越/符号链接/过量文件与冲突；跨端点剪切复制成功而删除失败；直传不可用转 relay 时不泄露凭据，审批取消不执行。

### 11.3 Terminal 功能、渲染和生命周期

- 本地和 SSH 共用 contract 测试；两个远程 tab 各自运行不同标识命令，切换/分屏/拖拽后原 shell 保持；关一个 PTY 后 SFTP 与另一个 PTY 可用。
- session generation 回归：延迟 read/resize/open/close 与切换/断线交错；旧响应不得写入新 xterm；React mount/unmount/StrictMode 下资源不重复创建。
- cursor 连续/重复 read、64 KiB 上限、约 256 KiB 历史溢出与 truncated、stale lease、takeover/release、recovery available=false、backend stopped、重连新 session。
- 八种编码逐字节切 chunk，包括中文/日文/韩文/emoji 与非法尾部；输入回显同编码；ZMODEM 原始字节不被转码或录制插件破坏。
- vim/top/less alternate screen，ANSI 颜色/光标，中文宽字符/组合字符，选择/复制/搜索/滚动，resize/reflow，标题/bell/OSC/cwd；复杂全屏程序不只测 echo。
- 隐藏标签、最小化/恢复、窗口连续 resize、不同 DPI/系统缩放/字体加载/主题切换、长输出与慢消费者；截图与真实 Tauri 手动录像/记录证明渲染效果。
- Shell integration 的命令开始/结束、退出码/cwd、未知 Shell 降级；命令取消/超时确实作用于运行边界，不用按键注入代替进程终止保证。
- 广播目标范围/失败、危险/多行粘贴、bracketed paste、vi/输入法；锁定后键盘/粘贴/广播/AI/MCP 都不可写，回放不写 live session。
- 录制开关/权限/容量/清理、asciicast 导入导出与回放 resize；ZMODEM 上传/下载/取消和路径约束；诊断采集本身不大量拖慢终端。

## 12. 安全默认值与完成定义

| 项目 | 默认/规则 |
|---|---|
| Host Key | Strict；未知需独立核验，changed 默认拒绝；撤销优先；Insecure 不进入正常生产配置 |
| Agent 登录 | 用户选择认证方式；provider 自动检测有明确结果，不静默退回别的凭据 |
| ForwardAgent/私钥加入 Agent | 默认关闭；分开授权；显示会话影响与 Agent 身份驻留信息 |
| 跳板与代理 | 默认无；各层认证/信任独立；不自动启动 ForwardAgent |
| X11/本地远程动态转发 | 默认关闭；监听优先回环；开放外部地址单独确认 |
| 旧算法 | 默认关闭；禁止自动降级；记录实际协商结果 |
| 覆盖/递归删除/解压 | 默认询问和范围预览，仍受权限/审批约束；不能绕过远端权限 |
| 传输 | 有界并发；重试不等于断点续传；暂存/校验/发布后才完成 |
| 录制/历史/AI 上下文 | 默认不采集敏感正文；按功能显式开启、限制范围并可清理 |
| 私钥与签名 | 私钥不发送远端；协议必要公钥/签名响应可流转，禁止进入通用日志 |
| 重连/恢复 | 不重放命令、不假装旧 PTY 活着；lease/cursor/布局不能替代真实资源 |
| 本系统既有优势 | 远程探测、Agent/Bundle 部署、manifest/SHA256/安装继续保留，接入统一服务而非被替换 |

**完整升级的完成条件：** S01～S26、F01～F25、T01～T28 全部有对应实现、消费方和验证证据；已有基础能力完成回归、缺失能力完成闭环；每个平台差异和不支持的条件明确可见。不得只做 SSH Agent/ForwardAgent/Terminal 子集，也不得把 SFTP 文件管理、高级终端、直传、监控或 AI/MCP 永久留作无交付的“后续考虑”。

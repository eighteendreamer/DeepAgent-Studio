缓存的三种含义
  • 本地环境 / Git / 工具配置复用，只影响准备成本，不代表模型 prompt cache 命中。
  • 稳定 instructions 与运行时 snapshot 分开；Messages 非 DeepSeek 域名额外标记 ephemeral：稳定首个 system 块、按名称排序后的最后一个工具、最后一条消息之前最近的 assistant text/tool_use 块。
  • 供应商返回的 usage 才是命中证据。Messages 的 prompt = input_tokens + cache_creation_input_tokens + cache_read_input_tokens；hit = cache_read；miss = input + cache_creation。

  
UI / CLI / Harness 的入口边界
主图追踪的是桌面正常消息 runChat → start_chat_v2。CLI / app-server 的 prepared admission 可以提前冻结配置和工具，但最终仍进入 RunAssembler / AgentKernel / ModelClient。内置 slash 控制命令会先分流，不应绘成必然发送模型的普通提示词。远程终端、Canvas、MCP 业务 API 不是此处的模型 HTTP Body；它们在工具 / 分支层接入。

## 2. 开发与验证纪律

1. 阅读当前生产方、消费者、DTO、测试及依赖源码；先写真实行为反例，再实现，不复制 navop 代码。
2. 每个切片记录 RED 原始结果，随后 GREEN、重构/回归。新增 API 缺失引起的编译失败标为契约 RED，不能冒称运行断言失败。
3. 原始输出置于忽略的 `target/remote-upgrade/`，摘要写入本文并通过正常 Git commit 留痕。不提交密钥、凭据、用户日志或运行缓存。
4. 测试使用临时目录、生成公钥、loopback 和可控假数据，不连接用户服务器，不操作用户私钥/系统 Agent 身份。
5. 先执行子集测试获得快速反馈，再执行 crate/前端构建/Tauri 等相应门禁。复用增量缓存，同一 Cargo target 的构建顺序执行，避免并发争锁；记录冷编译与热测试耗时，禁止为提速去掉断言或安全检查。
6. UI 验收分组件交互/受控浏览器/真实 Tauri 三种范围；build、SSR 和受控 mock 都不能单独证明真实 SSH 端到端完成。未执行范围明确列出。
7. 稍微偏离方案的修复须记录原因、影响和回归；不覆盖当前无关变更，不把已有其他任务成果重复计功。

## 3. R001：已信任主机密钥可视检查

### 3.1 范围与设计依据

- 能力：S16/S17/S26 的首个可视化切片，不宣称完成 M1 全部功能。
- 当前缺口：主工作台 RemoteSidebar 和设置页共用 `SshHostTrustField`，但只能输入信任文件路径，不能看到该 host/port 对应的算法和 SHA256 指纹。
- 本地设计：增加只读检查 API，复用生产 `HostTrust` reader 和应用专用默认路径。只读指定 known_hosts，不网络探测、不发送认证、不录入/覆盖公钥、不新增连接存储。
- 借鉴源：navop `crates/ssh/src/host_key.rs` 的 `HostKeyDetails`、`list_known_hosts` 及 SSH 指南中的指纹/算法展示；具体链接见完整方案 N02/N26。不是复制其 JSON trust store 或 GUI。
- 两个表单使用同一组件：显式点击才检查，展示加载/算法/指纹/文件来源/行号/错误；目标或路径变化后丢弃旧请求结果。提示“仅检查本地信任，不代表远端服务器已通过校验”。

### 3.3 UI 验收与响应速度

- 真实挂载生产 `RemoteSidebar` 和 `ConnectionsSettings`，共用生产 `SshHostTrustField`、shadcn、i18n 和 Tauri API wrapper；仅用受控 `__TAURI_INTERNALS__.invoke` 返回合成数据，不连接真实 SSH、不读用户文件、不修改用户连接。
- 浏览器实际操作：主工作台“选择连接→新建连接”，无 host 禁用检查；填写 host/port 后显示算法/SHA256/应用默认信任路径/真实行号字段与“不是远端验证”提示。点击后表单未被提交。
- 更换目标后旧指纹消失；使用延迟 response 显示“检查中”并禁用按钮，但仍能编辑目标、关闭窗口、切换设置。释放旧响应后不污染设置页。
- 设置页“编辑连接”保留显式信任路径；不可读错误可见，修改路径重试后恢复算法/指纹显示。1280×720 截图已实际查看，输入与结果可读；小屏和滚动到底部未另验，不是完整 Tauri WebView 验收。
- 截图：`target/remote-upgrade/r001-settings-ui.png`；受控 harness 归档在 `r001-ui-harness.html/.tsx`。原临时 HTML/TSX 已移出应用源码树，本轮临时 Vite 停止，不作为生产路由/配置提交。
- 首次打开早于 Vite 就绪出现 connection refused，等待同一服务真正 ready 后新开验收页成功；未通过关闭保护/网络代理绕过解决。Vite 冷启动约 38 秒，浏览器受控成功响应 0.1～0.3 ms 仅是假数据处理时间，**不能作为真实后端性能收益**。
- 快速反馈：前端 11 项约 0.81 秒、SSH 含增量编译约 11.44 秒，比每次完整前端构建 246.63 秒更适合 TDD 内循环；整包门禁仍执行。检查不自动随每次输入读取文件，无轮询，重复点击被合并；文件 I/O 在后端 blocking pool，UI 不锁住。
- 指纹只在显式 inspection 时计算，不给每次 PTY 读写触发的既有信任复核增加逐 key 的 SHA256 指纹生成；这是避免新增热路径开销，不冒称已修复全部 Terminal 性能问题。
- 未验：真实 Tauri IPC/系统窗口、Linux/macOS、真实外部 SSH/用户 Agent。不得从受控 UI 与编译通过推定这些环境已完成。

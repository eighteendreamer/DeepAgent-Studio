# 插件详情能力卡片紧凑化设计

## 范围

仅调整插件详情页的能力计数区域。详情头部、操作按钮、状态标签、信息列表和数据来源保持不变。

## 视觉设计

- 保留技能、MCP、钩子、命令、应用、样式六张卡片及零值。
- 卡片采用固定 `102 × 56px` 尺寸，左对齐排列。
- 卡片间距为 `8px`，容器使用可换行的 flex 布局。
- 卡片圆角缩小为 `6px`，内边距为横向 `10px`、纵向 `8px`。
- 标签使用中文、`10px` 常规字重，不使用全大写或额外字距。
- 数值使用 `16px` 半粗字重，标签与数值间距为 `4px`。
- 窄屏保持相同卡片尺寸并自然换行，不拉伸卡片填满整行。

## 交互与数据

卡片仍然直接展示 `Plugin` DTO 中现有的六个计数字段，不增加请求、状态或交互。零值与非零值使用同一结构，保证所有插件的能力维度稳定可比较。

## 验证

- 增加详情能力卡片布局回归检查，约束固定宽度、紧凑间距和中文标签。
- 运行前端生产构建，验证 TypeScript 和 Tailwind 类名。
- 在宽屏和窄屏下确认六张卡片不会溢出或拉伸。

# Runtime logos

These assets identify the corresponding runtime projects. They are bundled locally and are not fetched by the app.

| Asset | Upstream source |
| --- | --- |
| `node.svg` | [Node.js branding](https://nodejs.org/en/about/branding), `nodejsHex.svg` |
| `python.svg` | [Python Software Foundation logos](https://www.python.org/community/logos/), icon-only SVG |
| `temurin.png` | [Eclipse Adoptium brand kit](https://adoptium.net/docs/logo-styleguide/temurin-logo.zip), RGB V3A |
| `whisper.png` | [OpenAI's official GitHub profile](https://github.com/openai), used for the Whisper model family, which has no separate logo in its source repository |
| `whisper-cpp.jpg` | [whisper.cpp README](https://github.com/ggml-org/whisper.cpp), upstream project artwork |
| `ffmpeg.ico` | [FFmpeg website favicon](https://ffmpeg.org/favicon.ico) |
| `pandoc.svg` | [Pandoc website source](https://github.com/jgm/pandoc-website/blob/master/pandoc-icon.svg), by Albert Krewinkel ([CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)) |
| `chromium.svg` | [Chromium product icon](https://github.com/chromium/chromium/blob/main/chrome/app/theme/chromium/product_logo.svg), used for its PDFium library, which has no separate public project logo |
| `libreoffice.png` | [LibreOffice desktop application icon](https://github.com/LibreOffice/core/blob/master/sysui/desktop/icons/hicolor/48x48/apps/main.png) |

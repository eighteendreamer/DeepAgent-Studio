# Bundled typefaces

DeepAgent Studio ships these upstream font files for offline use. All are licensed under the SIL Open Font License 1.1. The license notices below are distributed with the app. The `DeepAgent …` names in CSS are family aliases; the font binaries are unchanged.

| Family | Upstream and pinned source | License |
| --- | --- | --- |
| Inter | [Inter v4.1](https://github.com/rsms/inter/tree/v4.1/docs/font-files), variable web fonts | [OFL](inter.txt) |
| Source Sans 3 | [Adobe Source Sans 3.052R](https://github.com/adobe-fonts/source-sans/tree/3.052R/WOFF2/VF), variable WOFF2 | [OFL](source-sans-3.txt) |
| Carlito | [Carlito](https://github.com/googlefonts/carlito), a Calibri-compatible office typeface; [Google Fonts binaries](https://github.com/google/fonts/tree/605c9f29dd5770762bd7ee8ea8ac4ae7664b2b7b/ofl/carlito) | [OFL](carlito.txt) |
| Source Han Sans CN | [Adobe Source Han Sans 2.005R](https://github.com/adobe-fonts/source-han-sans/tree/2.005R/Variable/WOFF2/OTF/Subset), Adobe's Simplified Chinese regional subset | [OFL](source-han-sans.txt) |
| Cascadia Mono | [Microsoft Cascadia Code](https://github.com/microsoft/cascadia-code), the variant without programming ligatures; [Google Fonts binaries](https://github.com/google/fonts/tree/3dd78844021e948ceb633d1dcee3f7885561b5d9/ofl/cascadiamono) | [OFL](cascadia-mono.txt) |
| JetBrains Mono | [JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/variable), variable TTF | [OFL](jetbrains-mono.txt) |
| Fira Code | [Fira Code](https://github.com/tonsky/FiraCode); [Google Fonts binary](https://github.com/google/fonts/tree/5020a98352f1909554697e1da4132da253727138/ofl/firacode) | [OFL](fira-code.txt) |

The System option uses the existing fallback fonts. Segoe UI, Calibri and other fonts installed by the operating system are not distributed by DeepAgent Studio.

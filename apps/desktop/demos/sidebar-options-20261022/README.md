# 侧栏与对话区布局选择页

最初提供 A–D 四套预览。用户现已确认 D，并要求移除对话标题下方横线；第二版默认选中 D，正式界面也按该方向实现。

- A 贴边内嵌：单一底层、窄留缝，最接近参考站。
- B 悬浮画布：增加外侧留白与轻阴影，对话区的边界更松弛。
- C 双层卡片：侧栏和对话区都有完整边框与圆角。
- D 双栏导航：功能窄栏、项目会话栏、对话区三个层级。

参考：[HextaUI Chat Sidebar](https://hextaui.com/blocks/chat-sidebar) 和其公开演示。观察了内嵌对话面板、侧栏分组、会话选中态与搜索弹层；未复制品牌资产或受限组件源码。参考测量与截图在 `.codex/previews/sidebar-options-20261022/`。

预览复用项目的 Button、Input、Textarea、Slider、DropdownMenu、SpringDisclosure、按压反馈与 60% 连续圆角规则。界面文案取自现有功能名称，并添加明确标注的示例会话。所有数据操作只发生在预览页面内存中。

在 `apps/desktop` 运行：

```text
node demos/sidebar-options-20261022/build.mjs
```

输出可离线打开的单文件 HTML：`.codex/previews/choice-preview-2026-10-22-sidebar-d-v2.html`。第一版 HTML 保留原样。

支持选择方案、浅深色切换、宽度/圆角/留缝调节、侧栏折叠、会话搜索、项目折叠、会话菜单、新对话、示例输入和复制选择结果。小屏幕使用抽屉侧栏。

本轮验证：独立 Vite 构建、严格 TypeScript 检查通过；离线单文件实际打开成功。在浏览器检查 375 / 768 / 1440 宽度，四方案桌面图与移动抽屉截图保存在上述预览目录。16 项交互检查覆盖主题、侧栏、搜索、项目、会话菜单及键盘返回焦点、新对话、输入、参数恢复、复制结果和减少动态效果设置。复制检查替换了页面内的 clipboard 接口以核对输出内容，没有覆盖用户剪贴板。正式 Tauri 布局本轮未修改或启动验证。

## 收起瞬间方角闪烁

收起回调此前调用 `runUiTransition`，与 `SpringDisclosure` 的 GSAP 宽度动画重叠。浏览器采样确认出现 `::view-transition-new(app-main-surface)` 等顶层截图动画；主内容自身为方角，截图离开父级圆角裁切时会短暂露出方形区域。

侧栏切换和关闭现直接更新布局状态，仅由 `SpringDisclosure` 动画宽度；页面导航仍保留原有 View Transition。新增两项回归检查覆盖快速切换与关闭后焦点返回，`pnpm test:sidebar` 共 13 项通过。前端类型检查和独立 Vite 生产构建通过；浏览器采样确认收起时不再生成 View Transition，外框圆角与 overflow 裁切保持稳定，最终宽度为 0。原生 Tauri 未启动验证。证据位于 `.codex/previews/sidebar-flicker-20261022/`。

# UI UX Pro Max

Provide priority-based UI/UX design recommendations for web and mobile: visual
styles, color palettes, typography pairings, layout patterns, product-type
reasoning, accessibility/UX guidelines, and chart selection — tailored to the
target stack (React, Next.js, Vue, and others).

## When to use

Use when designing or auditing an interface: a component, page, dashboard, or
full application; choosing a palette or font pairing; or selecting the right
chart for a dataset.

## Process

1. **Frame the context** — purpose, audience, platform (web/mobile), and stack.
2. **Pick a direction** — commit to a coherent aesthetic (minimal, editorial,
   brutalist, refined, etc.) rather than a generic default.
3. **Recommend system tokens** — palette (with roles), type scale + pairing,
   spacing, and motion guidance, expressed as reusable CSS variables.
4. **Map to product type** — apply the layout/UX guidelines for the product
   category (dashboard, marketing site, SaaS app, etc.).
5. **Choose data viz** — select chart types that match the data and question.
6. **Audit** — check contrast/accessibility, hierarchy, and consistency.

## Notes

- Prefer distinctive, intentional choices over generic AI aesthetics.
- Always provide accessible color contrast and semantic type scales.
